# Glados-checkin-repair

> 基于原 Glados 签到脚本的修复与增强版本。适配 `glados.cloud` 新域名，修复签到失败问题，并新增**积分**、**连续签到**、**套餐等级**、**流量用量**等信息推送。

---

## 📖 项目说明

感谢不知名大佬的原始 Glados 签到脚本。本项目在原脚本基础上，针对 **Glados 域名更换**（`glados.one` / `glados.network` → `glados.cloud`）导致的签到失败问题进行了修复，同时整合了 `status` 和 `points` 两个接口的全部可用字段，让推送信息更加完整。

---

## ✨ 功能特性

- ✅ 适配 `glados.cloud` 新域名与 API
- ✅ 自动获取并解析 `status` / `points` 接口数据
- ✅ 推送展示：
  - 账号邮箱
  - 签到结果
  - 剩余天数
  - 剩余积分
  - 今日签到得分
  - 连续签到天数
  - 套餐等级（按 VIP 值映射）
  - 本月已用流量 / 套餐额度
  - 剩余抽奖次数
  - 节点端口与地区
  - 邀请码
  - 官方公告提醒
- ✅ 支持 **PushPlus** 等多种通知渠道（依赖青龙自带 `sendNotify.py`）
- ✅ 可选 **自动兑换积分**（默认关闭）

## 🚀 部署与使用（青龙面板）

### 1. 创建订阅

在青龙面板中，进入 **订阅管理 → 创建订阅**，将以下命令复制到名称中：

```bash
ql repo https://github.com/JackieBan/Glados-checkin-repair.git "checkin.py" "" ""
```

填写名称与定时规则（例如 `40 0 * * *`），然后确定。

### 2. 添加依赖

进入 **依赖管理 → 创建依赖**，添加以下 Python 依赖：

```
requests
```

### 3. 运行订阅

在订阅列表中，点击刚才创建的订阅，执行一次以拉取脚本。

### 4. 创建环境变量

进入 **环境变量 → 创建变量**：

- **名称**：`GR_COOKIE`
- **值**：你的 Glados Cookie

#### 如何获取 Cookie

1. 浏览器打开 [https://glados.cloud](https://glados.cloud) 并登录
2. 按 `F12` 打开开发者工具
3. 切换到 **网络（Network）** 标签
4. 按 `Ctrl + R` 刷新页面
5. 点击第一行请求，在 **请求标头** 中找到 `Cookie` 字段
6. 完整复制 `Cookie` 的值，粘贴到青龙环境变量中

> 💡 多个账号请用 `&` 或换行分隔。

### 5. 首次运行

进入 **定时任务**，找到 `checkin.py` 相关任务，**手动运行一次**确认能正常签到并推送。

## ⚙️ 可配置项

脚本顶部提供以下配置：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `AUTO_EXCHANGE` | `False` | 是否开启自动兑换积分 |
| `EXCHANGE_PLAN` | `"plan500"` | 兑换档位：`plan100` / `plan200` / `plan500` |
| `EXCHANGE_COST` | `500` | 对应所需积分 |
| `SHOW_EXTRA` | `True` | 是否推送扩展信息（流量 / 端口 / 公告等） |

## 🧩 套餐等级映射说明

由于 Glados 官方 API **不直接返回套餐名称**，脚本根据 `vip` 值进行映射（参考官方套餐页）：

| VIP 值 | 套餐 | 月流量额度 |
|--------|------|------------|
| `>= 41` | Team | 2000 GB/月 |
| `>= 31` | Pro | 500 GB/月 |
| `>= 21` | Basic | 200 GB/月 |
| `< 21` | Free | 10 GB/月 |

> 如官方后续在 API 中返回真实套餐字段，只需修改 `map_plan_by_vip()` 一个函数即可。

## 🔧 主要修复点

| 问题 | 修复方式 |
|------|----------|
| 域名更换导致签到失败 | 全部接口改为 `glados.cloud` |
| `status` 接口无 `data` 字段导致解析报错 | 改用 `.get()` 逐层降级，兼容 `data` / `result` / 顶层 |
| 积分显示"未知" | 单独请求 `/api/user/points` 获取积分 |
| 剩余天数解析失败 | 兼容 `leftDays` 多种字段格式 |
| 变量名覆盖 `time` 模块 | 改用 `remain` 变量名 |
| 网络请求无超时 | 全部请求加上 `timeout=20` |
